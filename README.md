# Soft Interior — сайт студии

Многостраничный сайт на **Next.js 16** (App Router) + **React 19** + **TypeScript**.
Стили — обычный CSS с дизайн-токенами и CSS Modules. Tailwind не используется.

Портфолио хранится в **Postgres** и редактируется в админке на `/admin`:
проекты, фото и видео (сжимаются автоматически при загрузке). Как это
развёрнуто на сервере — в [DEPLOY.md](DEPLOY.md).

---

## Быстрый старт

```bash
npm run dev          # запустить локально → http://localhost:3000
npm run build        # собрать продакшен-версию
npm run lint         # проверить код
npm run db:generate  # после правки src/lib/db/schema.ts — создать миграцию
```

Для портфолио и админки нужна база. Локально проще всего так:

```bash
docker run -d --name soft-interior-dev-pg -p 127.0.0.1:5442:5432 \n  -e POSTGRES_USER=si -e POSTGRES_PASSWORD=si -e POSTGRES_DB=soft_interior postgres:17-alpine
```

и в `.env.local`:

```
DATABASE_URL=postgres://si:si@127.0.0.1:5442/soft_interior
ADMIN_EMAIL=admin@test.local
ADMIN_PASSWORD=любой-пароль
```

При первом запуске сервер сам создаст таблицы, админа и перенесёт стартовые
проекты. Без `DATABASE_URL` сайт работает, но портфолио и админка недоступны.
Видео и фото HEIC обрабатываются только при наличии `ffmpeg` и `heif-convert`
(в Docker-образе они есть).

## Про «вёрстка прижата к левому краю»

Исходный файл из Claude Design был не сайтом, а **холстом с макетами**: три
артборда шириной 1440 px, выложенные в ряд. Слева они прижимались потому, что это
поведение редактора, а не ошибка вёрстки.

В проекте центровка решена один раз и на всём сайте — в компоненте
[`Section`](src/components/layout/Section.tsx):

- фон секции растянут на всю ширину окна;
- содержимое ограничено шириной `--container-max` и центрируется через
  `margin-inline: auto`;
- боковые поля задаёт `--container-padding`.

Обе величины лежат в [`tokens.css`](src/styles/tokens.css), раздел 7. Хотите
сделать сайт уже или шире — меняете одно число.

## Как поменять шрифты

Два файла, всегда в такой последовательности.

### 1. Подключить шрифт — [`src/styles/fonts.ts`](src/styles/fonts.ts)

```ts
import { Manrope } from 'next/font/google';

export const fontManrope = Manrope({
  subsets: ['latin', 'cyrillic'],
  weight: ['400', '500', '600'],
  display: 'swap',
  variable: '--font-manrope',
});
```

И добавить в массив в конце файла:

```ts
export const fontVariables = [
  fontCormorant.variable,
  fontJost.variable,
  fontManrope.variable,
].join(' ');
```

Шрифт скачается на этапе сборки и будет раздаваться с вашего домена — внешних
запросов к Google в рантайме нет.

### 2. Назначить на роль — [`src/styles/tokens.css`](src/styles/tokens.css), раздел 3

```css
--font-heading: var(--font-cormorant), Georgia, serif;   /* заголовки H1–H6 */
--font-body:    var(--font-jost), system-ui, sans-serif; /* текст, меню, кнопки */
--font-numeric: var(--font-heading);                      /* цифры и цены */
--font-eyebrow: var(--font-body);                         /* рубрики в разрядку */
```

### Про шрифт цифр

Сейчас цены, площади и счётчики набраны той же антиквой, что и заголовки, —
отсюда ощущение, что «шрифт цифр непонятный». Он вынесен в **отдельную роль**
`--font-numeric` специально: поменяв одну строку, вы измените начертание всех
чисел на сайте, не тронув заголовки.

```css
--font-numeric: var(--font-manrope), system-ui, sans-serif;
```

Работает это потому, что каждое число обёрнуто в компонент
[`<Num>`](src/components/ui/Num.tsx):

```tsx
<Num size="priceLg">31 500 ₽</Num>   {/* цена в тарифе  */}
<Num size="price">3 500 ₽</Num>      {/* цена в карточке */}
<Num size="stat">18 000 м²</Num>     {/* счётчик        */}
<Num size="step">01</Num>            {/* номер этапа    */}
<Num>128 м²</Num>                    {/* размер от родителя */}
```

Правило: любое число, которое читается как значение, оборачиваем в `<Num>`.

Там же рядом лежит `--font-numeric-features: 'tnum' 1` — цифры одной ширины,
чтобы колонки цен не «плясали». Убрать можно там же.

## Как поменять цвета

[`tokens.css`](src/styles/tokens.css), разделы 1 и 2. Уровня два — это важно.

**Раздел 1 — палитра.** Сами оттенки:

```css
--palette-sand-100: #f4efe8;      /* основной фон */
--palette-espresso-900: #221e1a;  /* тёмные секции и кнопки */
--palette-brass-500: #8b7355;     /* акцент */
```

**Раздел 2 — роли.** Где какая краска применяется:

```css
--color-bg: var(--palette-sand-100);
--color-text: var(--palette-espresso-800);
--color-accent: var(--palette-brass-500);
```

Компоненты обращаются **только к ролям**. Отсюда два сценария:

| Задача | Что править |
|---|---|
| «фон должен быть теплее» | значение краски в разделе 1 |
| «акцент должен быть не латунным, а зелёным» | заводите краску в разделе 1, переназначаете `--color-accent` в разделе 2 |

⚠️ Если меняете `--palette-espresso-800` или `--palette-cream`, поправьте рядом
и `--rgb-ink` / `--rgb-cream` — из них собираются полупрозрачные границы.

## Как поменять размеры и отступы

| Что | Где | Пример |
|---|---|---|
| Размер заголовков | раздел 4 | `--text-h1`, `--text-h2`, `--text-hero` |
| Размер цен и цифр | раздел 4 | `--text-price-xl`, `--text-stat` |
| Толщина начертаний | раздел 5 | `--weight-heading` |
| Межстрочный интервал | раздел 5 | `--leading-relaxed` |
| Разрядка (letter-spacing) | раздел 5 | `--tracking-eyebrow` |
| Отступы между элементами | раздел 6 | `--space-1` … `--space-24` |
| Воздух между секциями | раздел 6 | `--section-padding-y` |
| Ширина контента | раздел 7 | `--container-max` |
| Боковые поля | раздел 7 | `--container-padding` |
| Скругления | раздел 8 | `--radius-sm` |

**Скругления.** По всему сайту — небольшое единое скругление: кнопки и бейджи
на `--radius-sm: 6px`, карточки услуг/отзывов/фото на `--radius-md: 10px`,
крупные таблицы (пакеты, смета) на `--radius-lg: 14px`. Хотите острее — верните
значения ближе к 0; мягче — увеличьте. Правите три числа в разделе 8 —
меняется весь сайт разом.

**Адаптив.** В самом низу `tokens.css` те же переменные переопределяются на
1200 / 900 / 640 px. То есть «сделать заголовки на телефоне меньше» — это одна
строка, а не правка каждого компонента.

## Как поменять тексты

Всё, что можно прочитать глазами, лежит в [`src/content/`](src/content) —
обычные TypeScript-файлы без вёрстки.

- цены и состав услуг → `services.ts`, `packages.ts`
- кейсы портфолио → **админка `/admin`** (новый проект, фото и видео;
  страница `/projects/<slug>/` создастся сама)
- статьи блога → `posts.ts` (новая статья = новый объект, страница
  `/blog/<slug>/` создастся сама)
- лента инстаграма → `instagram.ts`
- вопросы → `faq.ts` (попадают и в микроразметку FAQPage — то есть в сниппет
  поисковика)
- телефоны, адреса, меню, реквизиты → [`src/config/site.ts`](src/config/site.ts)

## Как добавить фотографии

**Фото и видео проектов** добавляются в админке: перетащите файлы на страницу
проекта. Сервер сам сожмёт их (фото — AVIF и WebP в четырёх размерах, видео —
MP4 1080p и 720p с обложкой), а браузер посетителя возьмёт подходящий файл.
Оригиналы остаются на сервере, но наружу не отдаются.

Остальные снимки (первый экран, команда, блог) пока стоят заглушками
([`ImageSlot`](src/components/ui/ImageSlot.tsx)). Чтобы поставить фото:

1. положите файл в `public/images/`, например `public/images/hero.jpg`;
2. добавьте `src` в нужный компонент:

```tsx
<ImageSlot
  src="/images/hero.jpg"
  alt="Гостиная в квартире 128 м², ЖК «Прайм Парк»"
  preload                               // только для главного кадра первого экрана
  sizes="(max-width: 1100px) 100vw, 55vw"
/>
```

Такие файлы не проходят автоматическое сжатие — кладите их уже сжатыми
(WebP, до 2000 px по длинной стороне, до 300 КБ). **`alt` заполняйте осмысленно** — это и доступность, и поиск по
картинкам.

## Два города: Москва и Сочи

Сайт живёт на двух адресах с одинаковой структурой:
`soft-interior.ru` (Москва, основной) и `sochi.soft-interior.ru`. Так страницы не конкурируют
между собой в выдаче, а объявления Директа ведут в нужный город.

Оба домена обслуживает один сервер. [`src/proxy.ts`](src/proxy.ts) по домену
запроса выбирает город и незаметно переписывает адрес: `sochi.soft-interior.ru/remont/`
→ `/sochi/remont/`. Поэтому все страницы лежат в `src/app/[city]/` и получают
город из `params`: серверные компоненты — параметром `city`, клиентские —
через `useCity()` ([`city-context.tsx`](src/config/city-context.tsx)).

Город меняет заголовки, телефоны, адреса, canonical, sitemap и robots.
Переключатель в шапке ведёт на другой поддомен — адреса в `src/config/site.ts`.

Локально город выбирается по домену, поэтому `localhost` — это Москва. Сочи
можно открыть, например, через `curl -H "Host: sochi.soft-interior.ru"`.

## Всплывающая карточка

Маленькая карточка в углу с предложением рассчитать объект. Сделана намеренно
скромной: страницу не затемняет, фокус не забирает, читать сайт можно, не
закрывая её.

Правила показа — в [`src/content/popup.ts`](src/content/popup.ts) вместе с
текстами:

- появляется через 30 секунд на странице или раньше — когда человек пролистал
  45% (то есть уже что-то читает, а не случайно зашёл);
- пока форма расчёта на экране — прячется: предлагать расчёт поверх самой формы
  бессмысленно, а на мобильном карточка ещё и закрыла бы кнопку отправки;
- закрыли — молчит 14 дней (отметка в `localStorage`, ключ `si-popup-dismissed`);
- закрывается крестиком, ссылкой «Не сейчас» и клавишей Esc.

Кнопка ведёт к форме на текущей странице, а если формы на ней нет (блог,
контакты, юридические страницы) — на главную к якорю `#zayavka`.

Убрать карточку совсем — удалить `<PromoPopup />` из
[`src/app/layout.tsx`](src/app/layout.tsx).

## Инстаграм на странице блога

Официальный эмбед Instagram мы **не используем сознательно**. Meta заблокирована
в России: без VPN не грузится ни скрипт `embed.js`, ни картинки с их CDN — у части
посетителей вместо ленты был бы пустой прямоугольник.

Поэтому превью лежат у нас и отдаются с нашего домена. Как добавить пост:

1. открыть пост в инстаграме, сохранить картинку (квадрат, от 800×800);
2. положить файл в `public/images/instagram/`;
3. добавить объект в массив `posts` в
   [`src/content/instagram.ts`](src/content/instagram.ts): путь в `image`,
   ссылку на пост в `href`, подпись в `caption`.

Ссылки на посты открываются в новой вкладке и работают только с VPN — об этом
честно написано под лентой. Рядом стоит ссылка на телеграм-канал: он тоже
требует VPN, поэтому в тексте мы его никак не рекламируем, просто даём ссылку.
Сама лента видна всегда и всем.

Дисклеймер про Meta (признана в РФ экстремистской организацией) — обязателен
по закону, он лежит там же в `instagram.ts`, поле `disclaimer`. Не удаляйте его.
